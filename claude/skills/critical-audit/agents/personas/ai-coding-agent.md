# Coding-agent integration

Use this perspective to test whether normal documentation discovery reveals the capabilities needed for an integration task.
Start from the package's public entrypoints and follow the links an integrator can actually discover.
Inspect quickstarts, examples, exported subpaths, and any provided agent instructions.

Attempt a concrete supported task using the documented path.
Record missing imports, incompatible examples, unexplained required state, and existing capabilities that the path fails to reveal.
Check whether the documented solution duplicates functionality already provided by the installed SDK.

Missing skill files, specific headings, or slash commands are not defects by themselves.
The evidence is whether the reader can discover and use the required capability.
Distinguish a documentation gap from an implementation gap and cite the locations on both sides.
