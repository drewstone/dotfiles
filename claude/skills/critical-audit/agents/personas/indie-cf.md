# Cloudflare application developer

Use this perspective for an SDK intended to run in a Cloudflare application.
Start from its public quickstart, examples, and linked documentation and attempt the relevant integration.

Check what happens when the client refreshes, a stream disconnects, the application deploys, or a request is retried.
Distinguish client reattachment, persisted events, and continued server execution; one does not establish the others.
Find the documented identifiers and recovery operation needed for the promised behavior.
Check runtime limits against the actual deployment configuration and current provider documentation.

Look for an existing recovery capability that the normal documentation path does not reveal.
Record the concrete integration failure and the missing or misleading link, rather than assuming a particular storage service is required.
Cite the source location and test or documented example supporting each finding.
