# Source coverage and research evidence

Choose a search window that fits the question and record it.
Enumerate the author's work from the relevant primary indexes, then cross-check identities and missing records across sources.
For cryptography, include IACR ePrint; for systems and AI, cross-check arXiv and DBLP where applicable.
A single aggregator's partial author profile does not establish complete coverage.

Fetch original HTML or PDF text for the claims you retain.
Verify quotations, referenced tables, code releases, cited baselines, and claims of prior work against those artifacts.
Keep source identity and page or section location with each claim.
Mark inaccessible work as unavailable and inferred gaps as inferred.

Search for later work that solves or narrows each shortlisted problem.
Record whether it remains open, is partially addressed, or is already solved.
A small finite experiment cannot settle an asymptotic claim unless the problem establishes that implication.

Assess both value to the intended user and whether a reproducible computation, construction, or proof check can make progress.
Name missing data, inaccessible compute, and checks that must be built before the experiment can be trusted.
Share source caches and rate limits across parallel workers; independent workers do not receive independent provider quotas.
